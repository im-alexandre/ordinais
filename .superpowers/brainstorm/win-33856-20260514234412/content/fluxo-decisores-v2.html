Fluxo revisado: projeto individual ou coletivo

O criador pode seguir sozinho ou convidar outros decisores por link.

Ponto de decisão após configurar o projeto
Fluxo individual

1. Criador configura projeto
2. Clica em continuar para avaliação
3. Sistema usa o criador como decisor único
4. Resultado pode sair ao concluir a avaliação
Fluxo coletivo

1. Criador configura projeto
2. Clica em adicionar decisores
3. Sistema gera links individuais
4. Resultado aguarda todos concluírem
A

Pedir nome do criador/decisor
