Fluxo proposto para múltiplos decisores

Um criador configura o projeto; decisores adicionais entram por link quando existirem.

Jornada principal
1. Criar projeto
Projeto pode nascer com 1 decisor.
2. Configurar dados
Classes, critérios, alternativas e parâmetros globais.
3. Adicionar decisores
Botão cria decisores e links individuais.
4. Cada decisor avalia
Link abre a avaliação daquele decisor.
5. Resultado
Liberado quando as avaliações necessárias estiverem completas.
A

Peso igual entre decisores

Todos os decisores contribuem igualmente na agregação antes do ELECTRE-MOr.

B

Peso configurável por decisor

O criador define a importância de cada decisor antes de liberar o resultado.
